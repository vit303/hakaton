# Hakaton — RAG-система для работы с документами

Проект предназначен для обработки документов и использования языковых моделей для поиска и анализа информации. В репозитории находятся компоненты RAG, вспомогательные скрипты и тесты.

## Возможности

- Обработка документов различных форматов: PDF, DOCX, PPTX и других поддерживаемых форматов.
- Подготовка текстовых данных для поиска и последующего анализа.
- Использование моделей Hugging Face для обработки информации.
- Использование векторных представлений текста для семантического поиска.
- Организация компонентов проекта в виде отдельных модулей и скриптов.

## Технологический стек

| Технология | Назначение |
|---|---|
| Python | Основной язык программирования |
| Hugging Face Transformers | Работа с языковыми и мультимодальными моделями |
| Qwen3-VL-4B-Instruct | Модель для обработки текста и визуальной информации |
| BAAI/bge-m3 | Модель для получения эмбеддингов |
| PyMuPDF | Извлечение информации из PDF |
| python-docx | Обработка DOCX |
| python-pptx | Обработка презентаций PPTX |
| Pandas, NumPy | Работа с данными |
| python-dotenv | Загрузка настроек из `.env` |

## Требования

Перед установкой убедитесь, что у вас установлены:

- Python 3.10 или новее.
- Git.
- Доступ к интернету для установки зависимостей и загрузки моделей.
- Свободное место на диске для библиотек и файлов моделей.

Для ускорения обработки моделей рекомендуется использовать совместимую видеокарту NVIDIA с настроенным CUDA. Запуск на CPU может быть значительно медленнее.

## Установка

### 1. Клонирование репозитория

```bash
git clone https://github.com/vit303/hakaton.git
cd hakaton
```

### 2. Создание виртуального окружения

**Windows:**

```powershell
python -m venv .venv
.venv\Scripts\activate
```

**Linux / macOS:**

```bash
python3 -m venv .venv
source .venv/bin/activate
```

### 3. Обновление pip

```bash
python -m pip install --upgrade pip
```

### 4. Установка PyTorch

Установите версию PyTorch, подходящую для вашей конфигурации CPU или CUDA.

Инструкция и команда установки доступны на официальном сайте:

https://pytorch.org/get-started/locally/

Проверьте установку:

```bash
python -c "import torch; print('PyTorch:', torch.__version__); print('CUDA available:', torch.cuda.is_available())"
```

Если используется GPU, значение `CUDA available` должно быть `True`.

### 5. Установка зависимостей проекта

```bash
pip install -r requirements.txt
```

## Настройка

### 1. Создание файла `.env`

В корне проекта находится шаблон `.env.example`. Создайте на его основе файл `.env`.

**Windows:**

```powershell
Copy-Item .env.example .env
```

**Linux / macOS:**

```bash
cp .env.example .env
```

### 2. Настройка параметров

В файле `.env` предусмотрены следующие переменные:

```dotenv
QWEN_VL_MODEL=Qwen/Qwen3-VL-4B-Instruct
EMBED_MODEL=BAAI/bge-m3
HR_CONTACT=HR
```

Описание параметров:

- `QWEN_VL_MODEL` — идентификатор модели Qwen для обработки запросов.
- `EMBED_MODEL` — идентификатор модели для построения эмбеддингов и семантического поиска.
- `HR_CONTACT` — название или обозначение контакта HR, используемое приложением.

При необходимости измените значения в соответствии с конфигурацией проекта. Не добавляйте в публичный репозиторий пароли, токены и другие секретные данные.

### 3. Загрузка моделей

При первом обращении к моделям Transformers может скачать их веса из Hugging Face. Для этого потребуется подключение к интернету и дополнительное место на диске.

Если доступ к модели ограничен, предварительно настройте авторизацию в Hugging Face.

## Запуск

### 1. Проверка структуры проекта

Перед запуском найдите основной исполняемый файл проекта.

Из корневого каталога выполните:

**Windows PowerShell:**

```powershell
Get-ChildItem -Recurse -File -Include *.py |
    Select-Object -ExpandProperty FullName
```

**Linux / macOS:**

```bash
find . -type f -name "*.py"
```

Изучите файлы в каталогах `rag/` и `scripts/`, чтобы определить точку входа приложения.

### 2. Запуск приложения

После определения главного скрипта запустите его из корневого каталога проекта, при активированном виртуальном окружении:

```bash
python путь/к/главному_скрипту.py
```

Замените путь на фактический путь к исполняемому файлу, реализующему запуск приложения.

Если проект использует отдельные команды для индексации документов, запуска RAG-компонента или обработки запросов, выполняйте их в последовательности, предусмотренной соответствующими скриптами.

### 3. Проверка работы

После запуска убедитесь, что:

- приложение завершает инициализацию без ошибок;
- необходимые модели доступны;
- документы обрабатываются корректно;
- компоненты поиска и генерации работают в соответствии с реализованной логикой.

Если приложение запускает веб-сервер, адрес и порт следует брать из его конфигурации или сообщения в терминале.

## Тестирование

В репозитории предусмотрен каталог `tests/`.

Если тесты реализованы на `pytest`, установите его:

```bash
pip install pytest
```

Запустите тесты:

```bash
python -m pytest tests/ -v
```

Если тесты используют дополнительные сервисы, файлы или модели, предварительно настройте необходимые зависимости.

## Возможные проблемы

### Ошибка импорта модуля

Убедитесь, что виртуальное окружение активировано, а зависимости установлены:

```bash
python -m pip install -r requirements.txt
```

### CUDA недоступна

Проверьте версию PyTorch и совместимость установки с драйвером NVIDIA:

```bash
python -c "import torch; print(torch.__version__); print(torch.cuda.is_available())"
```

При необходимости переустановите PyTorch в соответствии с официальной инструкцией.

### Недостаточно видеопамяти

Уменьшите размер обрабатываемых данных или используйте более компактную модель, если это поддерживается реализацией. Также можно проверить возможность запуска на CPU.

### Ошибка загрузки модели

Проверьте подключение к интернету, доступность модели в Hugging Face и наличие свободного места на диске.

### Ошибка при обработке документов

Проверьте формат входного файла, корректность его содержимого и наличие необходимых библиотек для соответствующего формата.
